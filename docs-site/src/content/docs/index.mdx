## How it fits together

The code is split in two. **The core** is everything outside `src/site/`: rendering, the editor,
the admin, the database schema. **A site** is `src/site/`: its configuration, blocks, card designs,
colors and styles. The `supapuck-cms` repository holds the core and an example site (Example Town). A
real site is a fork that replaces `src/site/` and keeps `supapuck-cms` as its `upstream` remote, so core
updates merge in cleanly.

- [Local setup](start/local-setup/) gets the example site running.
- [Sites and upstream](start/sites-and-upstream/) explains how a site repository relates to the core.
- [Site configuration](site/configuration/) covers everything a site can set.
